# Async/Await vs Thread Pool

### Understanding Asynchronous Programming and Thread Management in .NET

A practical learning guide that explains how asynchronous programming works in .NET, what happens behind the scenes, and how Async/Await relates to the Thread Pool.

**Author:** Essraa Abd El-Rahman  
**Role:** .NET Developer  
**Level:** Beginner to Advanced

---

## 📘 About This Guide

This guide is designed to build a clear understanding of asynchronous programming in C# and .NET — from the basic concepts to advanced runtime behavior.

The goal is not simply to memorize definitions, but to understand what happens behind the scenes and when to use each approach in real-world backend development.

## 📚 What You'll Learn

- The problem that made us need async
- What is a Thread?
- Synchronous vs Asynchronous programming
- Understanding Async, Await, and Task
- How the .NET Thread Pool works
- The relationship between Async/Await and Thread Pool
- I/O-bound vs CPU-bound operations
- Hands-on experiments and practical examples
- Common pitfalls and performance issues
- Applying asynchronous programming in ASP.NET Core
- Advanced concepts:
  - Async State Machine
  - SynchronizationContext
  - ConfigureAwait(false)
  - Thread Pool Starvation vs Deadlock
- Decision table: What to use and when
- Deep dive: Who waits for the database?
- Task.Run and CPU-bound work
- Self-assessment questions
